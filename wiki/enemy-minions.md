# 敌人随从

敌方随从也被视为意图 actor，而不是“无意图自动攻击”的棋子。它们应拥有自己的意图显示和目标选择逻辑。

## 默认敌方随从意图

- 默认行为：每回合攻击随机合法玩家目标。
- 若玩家方存在嘲讽随从，则必须优先攻击嘲讽随从。
- 意图显示和实际执行应使用同一个缓存目标，避免“显示打 A，实际打 B”。

## 软泥怪

- 来源：史莱姆首领召唤。
- 概念定位：基础召唤物。
- 资源存在：`Minion_Slime.tres`。

## 机械静螳

- 来源：实习机械师召唤；也作为机械族卡牌存在。
- 身材：4 攻 / 3 血 / 0 防。
- 费用：3。
- 行动花费：1。
- 稀有度：4（铁卡）。
- 关键词：伏击。
- 特殊语义：作为实习机械师召唤物时额外获得嘲讽；拥有护甲时攻击力 +2 的概念出现过。
- 敌方随从意图：部署回合沉睡；之后循环攻击玩家目标，尊重嘲讽。

## 机械小蠊

- 来源：张郎召唤。
- 身材：1 攻 / 3 血 / 0 防。
- 费用：0。
- 行动花费：1。
- 稀有度：0（衍生）。
- 意图：
  1. 部署回合沉睡。
  2. 攻击随机玩家目标。
  3. 若敌方有空槽位，复制自身。
  4. 之后在攻击和复制之间循环；若不能复制则攻击。
- 目标池包括玩家英雄与玩家随从；若有嘲讽则优先嘲讽。

## 智能臭鸡蛋

- 来源：劫蛋者召唤。
- 身材：1 攻 / 3 血 / 0 防。
- 费用：1。
- 行动花费：1。
- 稀有度：0（衍生）。
- 关键词：亡语。
- 亡语：对敌方全体造成 4 点法术伤害。
- 敌方随从意图：自爆——在自己的敌方随从行动阶段自杀，触发亡语对玩家方全体造成法术伤害。
- 设计备注：
  - 亡语是随从本身的被动，阵营相对——玩家方死打敌方，敌方死打玩家方。
  - Brain 只驱动"自爆"意图（自杀），伤害由亡语机制（DeathHandler + CardEffectDispatcher）统一处理，不耦合在随从身上。
  - 若劫蛋者已有「蓄谋」，新召唤的臭鸡蛋会立刻获得对应层数的「聚焦」。
  - 法术伤害吃到敌方全局热力乘区与自身聚焦层数。

## 玩家卡牌也可作为敌方随从

以下卡牌可以作为玩家牌，也可能被敌人/机制引用为场上随从概念：

- 机械蜈蚣-防空型。
- 机械蜈蚣-攻城型。
- 骑士I型。
- 我的刀盾。
- 墓碑。
- 第18团。

实际是否作为敌方召唤物，由遭遇和卡牌效果决定。
