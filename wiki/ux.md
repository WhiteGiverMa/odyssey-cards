# 交互与表现 UX

本页记录游戏层与配套工具的交互表现概念。设计分辨率基准已全局统一为 **`1600×900`**。

## 战斗界面五段式布局（1600×900）

1. **顶部敌方牌手手牌栏（`EnemyHandBar`，70px）**：全员同构牌手化后，所有战斗（普通 10~20 张 / 精英 21~39 张 / Boss 40 张）均展示敌方手牌栏：
   - 未揭露手牌显示「星途暗金双环星盘」程序化卡背；
   - 被玩家「情报」揭露的明牌播放扫描流光动画并微缩展示真实卡面，鼠标悬停（或触控长按）弹出 `1.0x` 原尺寸高清预览浮层；
   - 右侧同步展示敌方当前手牌数、六边形法力水晶及牌库剩余张数。
2. **敌方英雄身份区（`EnemyArea`，120px）**：展示单名或多名敌方牌手的姓名、渐变血条、护甲、防御、武器射程/被动提示与状态栏。
3. **三线战术棋盘区（`BoardArea`，约 500px）**：
   - 上排 `敌方支援线（4 格）`、中排 `中央独占前线（5 格）`、下排 `我方支援线（4 格）`；
   - 底层 `FrontlineArenaBackdrop` 绘制阵地导轨与前线斜纹警示力场框，随前线归属（中立星灰 / 我方青金 / 敌方绯红）平滑呼吸变色；
   - 卡牌与棋盘槽位通过 `TacticalIconDrawer` 纯矢量绘制四兵种徽章（先锋棱盾、突击履带战车、支援仰角火炮、游击后掠飞梭）以及「八角重盾（嘲讽）」与「双翼侧护盾（守护）」微标。
4. **我方指挥官与军械区（`PlayerArea`，80px）**：展示我方生命、热力温度条、六边形法力水晶、武器平 A/主动技能按钮、牌堆查看、英雄技能、智能攻击与结束回合按钮。
5. **底部风扇手牌区（`HandArea`，110px）**：扇形交叠排布，悬停上浮放大；出牌阈值线为屏幕高度 `60%`，底部 `95%` 为取消区。

## 出牌、推进前线与「行进间射击」交互

### 手牌部署

- 点击选中再点槽位，或按住手牌拖入**我方支援线空槽**松手部署（桌面与移动端统一 10px 启动阈值，走 Godot 主指针路径）；无目标法术/领域拖入屏幕中部出牌区松手即可释放，右键或拖回底部取消。
- **反制牌激活与取消激活（0.2.2）**：在己方回合内将「反制」牌拖入屏幕中部出牌区（或点击激活），扣除费用后卡牌**留在手牌中**并亮起青金色「已激活」标记（开启 Emoji 对照模式时显示「⚡已激活」）；在己方回合结束前，随时再次将已激活的反制牌拖入出牌区即可取消激活并全额退还所花法力。

### 出牌亮牌定格与敌方回合逐步回放

- **双端指令/领域/反制亮牌演出（`CardShowcaseVfx`）**：无论我方或敌方施放指令（法术）、展开领域或触发反制拦截，卡牌都会先从手牌（敌方从顶部手牌栏中心）弹入战场左侧黄金展示位定格放大，底部配有纯色阵营标签（`我方指令` / `敌方指令` / `展开领域` / `反制触发` / `已被反制`）；若带有明确单目标，定格期间同步绘制指向目标的脉冲弧线与收缩靶环，停留供玩家阅读卡面后再飞向弃牌堆、抽牌堆或效果栏。
- **随从部署悬停亮牌与推进滑行**：双方随从部署时先抬升放大为可读卡面短暂悬停亮牌，再俯冲落入支援槽扬尘；普通随从推进中央前线播放平滑抬升滑行与阵营色流光尾迹（`MinionMoveVfx`）。
- **敌方同构牌手异步步进**：有战斗 UI 时，敌方牌手回合按每一步行动（抽牌回蓝 → 亮牌施法 / 部署 / 推进 / 攻击 / 技能）逐步停顿并实时刷新顶部手牌张数与法力水晶；无 UI 的自动化测试保持零延迟同步结算。
- **战斗动画速度调节**：设置页提供「战斗动画速度」倍率滑块（默认偏慢的 `×0.75`，确保交互与亮牌清晰易读），统一控制亮牌、部署、推进、弹道与敌方步进节奏。

### 左侧可折叠战术战报（`CombatLogDrawer`）

- 战斗界面左侧常驻窄条「战报」把手（默认热键 `L` 展开/收起，折叠态下敌方产生新行动时微光脉冲提示），展开后滑出半透明战术战报面板，面板外区域完全穿透不阻挡出牌操作。
- 按回合分组以 `主体 -> [纯色结果徽章] 目标`（如 `曼巴导弹 -> [伤 15] 宿敌·理惠`）记录部署、指令、领域、推进前线、攻击、武器/技能及嵌套被动/亡语聚合结果。
- **历史卡面特写与弃牌揭晓**：战报不仅展示主体与目标芯片，任何实际从手牌进入弃牌堆的卡牌（含敌方被「北风之神」「093B SSN」「黑水之下」弃掉的手牌，以及双方主动/技能弃牌）都会逐张渲染为带阵营描边的 `弃: {牌名}` 芯片；鼠标悬停（或触控点按）任意主体、目标或弃牌芯片，即在抽屉右侧安全区弹出 `1.0x` 原尺寸高清 `CardUI` 历史快照卡面。若弃牌效果或「北风之神」触发时对方已无可弃手牌，则不会生成弃牌芯片。
- **反制保密规则**：双方在手中挂上或取消待命反制牌时绝不写入战报、不亮牌，仅在反制牌真正触发拦截消耗时才揭晓记录。

### 棋盘推进与攻击手势

- 按住或点击我方随从时，同时高亮**可推进的中央前线空槽**与**合法敌方攻击目标**：
  - 悬停可进入的前线空槽：绘制**青绿色推进箭头（`move_select`）**，松手消耗 1 次行动油费推进占线；
  - 悬停合法敌方目标：绘制**橙色攻击箭头（`attack_select`）**，松手消耗行动油费开火；
  - **突击单位一步跨线直拖**：当前线可进且法力够付两段油费时，直接将我方支援线的「突击」坦克拖到敌方后排或敌方 HQ 身上松手，自动完成进前线 + 开炮，并以各 50% 概率随机触发两套演出彩蛋——**「滑入前线停稳架炮射击」**或**「冲锋滑行半途亮起炮口喷射曳光弹（行进间射击）」**！
- 键盘目标选择支持在 `我方支援线 ↔ 中央前线 ↔ 敌方支援线` 三行之间上下切换导航。

## 星途程序化视觉系统（0 外部贴图资产）

- **多层程序化卡图**：基于卡牌 ID 的确定性 FNV-1a 哈希种子派生，包含双焦点深空星云渐变、三大阵营精密底纹（绮梦/红裤衩系极坐标魔法星盘、理惠/溯光系机甲装甲切面与光学 HUD 准星、通用等高晶格）、双层复合主徽记、景深星尘星座连线与四角稀有度切角辉光（真图通道仍保留，有真图时优先）。
- **全局视觉与微交互**：FastNoiseLite 多层视差星空背景、路线地图贝塞尔曲线爬升节点（`MapPathView`）、按钮悬停缩放提亮（`MicroFX`）、敌我底座光环（`HeroAuraRing`）、护甲获得 `甲+N`（Emoji 对照模式下 `🛡+N`）跳字与老电视风双向表情飘字系统。
- **界面字体大小与纯色块符号模式**：
  - 设置页提供「界面字体大小」缩放滑块（默认放大至 `120%`），实时驱动全局共享主题与战斗 HUD / 战报 / 棋盘槽位文字尺寸，同时保持卡框内描述自适应不溢出；
  - 默认关闭 Emoji 图标（`UiSymbolMode`），状态效果栏、战报标签、按钮与浮字均采用纯色色块 + 简字徽章呈现（仅保留涩情文案开关与事件中的 `♥`/`♥️`），可在设置页勾选「启用 Emoji 图标（对照模式）」随时切回原生符号对比。

## 配套可视化工具：星图档案（`Tools/CardCollectionWeb`）

仓库内置对标 KARDS 官网体验的独立 TypeScript + React 全栈应用：

- 实时读取 `Resources/Cards/*.tres` 与中英 YAML，零静态副本延迟；
- 提供高精度 DPR HTML5 Canvas 程序化卡图陈列、多维兵种/油费/词条/卡包系列筛选、大图检视台与衍生卡跳转；
- 内置 **「卡包编排」工坊**：支持预览 7 大内置卡包（核心/无人智胜/未来追杀/超体计划/断流/预备/先锋）及 DIY 卡包，支持勾选多张卡牌一键归类到指定或新建卡包并无损写回 `.tres`；
- 内置卡组构筑器（10~20 张校验、费用曲线、兵种统计、一键按种子模拟生成主题卡组、导入导出）；
- 内置**可交互 `4 / 5 / 4` 防线规则沙盘**，可自由摆放四兵种与嘲讽/守护/护航/烟幕单位，实时高亮合法目标并输出拦截破锁分析。
