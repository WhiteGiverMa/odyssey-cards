# 交互与表现 UX

本页记录游戏层 UX 概念，不追踪具体代码结构。

## 卡牌出牌

### 点击模式

1. 左键点击卡牌，进入选中状态。
2. 卡牌跟随鼠标或进入目标选择表现。
3. 左键点击有效目标后打出。
4. 右键取消。

### 拖拽模式

1. 左键按住卡牌并拖拽。
2. 松手在有效目标上则打出。
3. 松手在无效区域则取消。

### Play Zone / Cancel Zone

- 无目标法术/领域可以拖到屏幕中部 Play Zone 后松手打出。
- 取消区概念来自 STS2：底部区域可作为取消返回手牌的语义。
- 当前项目对桌面与移动端的细节以实际 UX 为准。

## 随从攻击

- 点击随从可进入选择目标攻击状态。
- 按住随从可拖拽攻击。
- 攻击时从攻击者处拉出箭头，指向当前目标。
- 松手在合法敌方目标上执行攻击，非法位置取消。

## 武器攻击与主动技能

- 玩家英雄可使用武器攻击敌方英雄或敌方随从。
- 离子脉冲需要选择敌方英雄或敌方随从作为目标。
- 多敌人场景下，敌方英雄目标必须可以分别选中并高亮。

## 意图显示

- 敌方英雄和敌方随从都有意图。
- 攻击意图应显示目标与最终预览伤害。
- 敌方随从也应在棋盘槽位附近显示自己的意图。
- 意图显示和执行必须锁定同一个目标。
- 意图执行期间 UI 可以冻结，避免战场变化造成显示/执行错位。

## 箭头与弹道

- 玩家攻击箭头：橙色。
- 敌方攻击意图箭头：红色。
- 敌方对友方目标施加增益等辅助意图：蓝色箭头概念出现过。
- 攻击/法术/战斗弹道特效从攻击者飞向被攻击者。
- 普通反击不触发弹道，避免两路特效打架。
- “战斗”机制是双方互相造成攻击力伤害，可以双向触发弹道。
- 表现层不应阻塞操作。

## 手牌表现

- 手牌呈扇形或交叠排列，类似玩家手持一扇牌。
- 悬停时卡牌上浮、放大、便于阅读。
- 长英文卡名需要响应式字号，避免溢出。
- 卡牌描述可以支持居中/左对齐设置。

## 选牌与弃牌

- 发现/奖励：N 选 1，全屏或覆盖层展示完整卡牌 UI。
- 主动弃牌：可以单选或多选手牌，确认后进入弃牌堆。
- 手牌强制选 N 的效果如果没有实际选择空间（例如手牌数量不大于必须弃掉的数量，或只有 1 张可作为复制目标），可以直接结算，不必弹出选择交互；但“可选 0 到 N”这类数量本身有意义的效果仍应保留选择。
- 捞月等从弃牌堆选牌的效果复用选牌 UI 概念。
- 入场 350ms 防误触保护是可参考 UX。

## 信息、设置与移动端

- 综合信息界面查看层数、房间、卡组、藏品。
- 设置页在主菜单和暂停菜单应尽量同源。
- 设置页「显示」Tab →「特效」分区可分别调整弹道/卡牌飞行/伤害数字/表情文字的粒子尺寸缩放（0.0~2.0x）。
- 移动端需要统一输入所有权、弹窗栈、安全区和触控目标尺寸。
- Android Back 应优先处理弹窗/覆盖层/暂停，再回退主流程。

## 表情系统

- 敌人可以发送类似老电视/VCD 风格的飘出文本。
- 玩家一段时间没有出牌时，敌人随机发送催促表情。
- ChatScreen 可触发指定表情。
- 信息发送界面概念出现过：战斗中同一个输入框既可以输入 `/` 命令，也可以像聊天一样直接发送玩家表情/短消息。
- 玩家可维护多套「我的表情」预设组；战斗输入预设表情前缀时，应能出现补全候选并用 Tab 补全。
- 官方表情收藏集概念出现过：`星途卡牌官方表情收藏集`。其中条目在管理页以星标标记，战斗飘字可使用不同于普通表情的特殊样式。
- 当前观察到的 UX 状态（2026-06-18）：主菜单有「我的表情」入口；信息发送界面可发送普通玩家消息、官方表情，也可继续使用 `/emote <text>` 触发敌方表情；实现状态仍以实际 UX 和当前代码为准。

## 星途视觉系统

- 项目长期处于 0 美术资产状态，视觉装点全部由代码绘制（`_Draw` / StyleBoxFlat / FastNoiseLite / Theme / Tween），运行时内存生成，不写盘、导出安全。概念来源：2026-07-21 视觉审计与 PRD（GitHub issue #2）、handoff-20260721。
- **程序化卡图**：每张卡以卡牌 ID 为种子生成独一无二且可复现的卡面；卡面与卡牌类型有色彩关联（随从暖金、法术青蓝、领域紫罗兰）；高稀有度卡面有光晕区分（大师金环、极佳银环、良好铜环、专属橙环）；卡面符号风格按卡牌所属英雄主题分派（绮梦/红裤衩系偏魔法符文，理惠/溯光系偏机械线稿，其余通用几何抽象）。真实卡图资产的接入通道保留（有真图时优先显示真图）。
- **星空背景**：深空星云底纹 + 多层视差星点（漂移、闪烁）+ 偶发流星；主菜单、地图、战斗共用同一概念，密度与氛围分档（主菜单密星流星、地图中密度、战斗稀疏加战场中央微光）。
- **星途色板**：深空蓝紫底 + 星粉 + 青金 + 暖金；玩家阵营青金、敌方阵营绯红。色板集中管理，全局主题（按钮五态、面板、字色）统一。
- **法力水晶**：法力值以六边形水晶阵列逐颗点亮/熄灭呈现，替代纯文本主显示；数字文本保留为辅助。
- **棋盘阵营色**：槽位边框按阵营着色（玩家青金、敌方绯红）；空槽位边框呼吸脉动提示可放置区域，全场空槽同一相位。
- 当前观察到的 UX 状态（2026-07-21）：以上概念在主菜单、收藏、战斗、地图四界面均已可见；61 张卡均有独特卡面。
- 待决点（PRD #2 P2 项）：地图路线节点路径可视化、按钮/界面微交互动效、敌方身份卡横条改造（缩小信息条 + 底座光环）、全局主题推广到收藏/奖励/商店等其余界面、热力条与生命条图形化精修。
- 历史备注：STS 时代曾有一个按杀戮尖塔卡名生成纯色占位图的占位资源生成器，与当前卡牌零映射、从未被消费，已于 2026-07-21 随视觉系统落地删除；Assets 死图同步清理（212 → 24，仅保留备份资源引用的 Demo 图）。
