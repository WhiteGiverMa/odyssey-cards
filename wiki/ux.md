# 交互与表现 UX

本页记录游戏层与配套工具的交互表现概念。设计分辨率基准已全局统一为 **`1600×900`**。

## 战斗界面五段式布局（1600×900）

1. **顶部敌方指挥官手牌栏（`EnemyHandBar`，70px）**：仅在迎战拥有手牌/法力体系的精英或 Boss 指挥官时展开；普通意图小怪战自动隐藏并将空间让给棋盘。
   - 未揭露手牌显示「星途暗金双环星盘」程序化卡背；
   - 被玩家「情报」揭露的明牌播放扫描流光动画并微缩展示真实卡面，鼠标悬停（或触控长按）弹出 `1.0x` 原尺寸高清预览浮层；
   - 右侧同步展示敌方当前手牌数、六边形法力水晶及牌库剩余张数。
2. **敌方英雄身份区（`EnemyArea`，120px）**：展示单名或多名敌方英雄的姓名、渐变血条、护甲、防御、武器射程/被动提示与状态栏；道中小怪显示意图图标，主题卡组指挥官隐藏静态意图图标。
3. **三线战术棋盘区（`BoardArea`，约 500px）**：
   - 上排 `敌方支援线（4 格）`、中排 `中央独占前线（5 格）`、下排 `我方支援线（4 格）`；
   - 底层 `FrontlineArenaBackdrop` 绘制阵地导轨与前线斜纹警示力场框，随前线归属（中立星灰 / 我方青金 / 敌方绯红）平滑呼吸变色；
   - 卡牌与棋盘槽位通过 `TacticalIconDrawer` 纯矢量绘制四兵种徽章（先锋棱盾、突击履带战车、支援仰角火炮、游击后掠飞梭）以及「八角重盾（嘲讽）」与「双翼侧护盾（守护）」微标。
4. **我方指挥官与军械区（`PlayerArea`，80px）**：展示我方生命、热力温度条、六边形法力水晶、武器平 A/主动技能按钮、牌堆查看、英雄技能、智能攻击与结束回合按钮。
5. **底部风扇手牌区（`HandArea`，110px）**：扇形交叠排布，悬停上浮放大；出牌阈值线为屏幕高度 `60%`，底部 `95%` 为取消区。

## 出牌、推进前线与「行进间射击」交互

### 手牌部署

- 点击选中再点槽位，或按住手牌拖入**我方支援线空槽**松手部署（桌面与移动端统一 10px 启动阈值，走 Godot 主指针路径）；无目标法术/领域拖入屏幕中部出牌区松手即可释放，右键或拖回底部取消。

### 棋盘推进与攻击手势

- 按住或点击我方随从时，同时高亮**可推进的中央前线空槽**与**合法敌方攻击目标**：
  - 悬停可进入的前线空槽：绘制**青绿色推进箭头（`move_select`）**，松手消耗 1 次行动油费推进占线；
  - 悬停合法敌方目标：绘制**橙色攻击箭头（`attack_select`）**，松手消耗行动油费开火；
  - **突击单位一步跨线直拖**：当前线可进且法力够付两段油费时，直接将我方支援线的「突击」坦克拖到敌方后排或敌方 HQ 身上松手，自动完成进前线 + 开炮，并以各 50% 概率随机触发两套演出彩蛋——**「滑入前线停稳架炮射击」**或**「冲锋滑行半途亮起炮口喷射曳光弹（行进间射击）」**！
- 键盘目标选择支持在 `我方支援线 ↔ 中央前线 ↔ 敌方支援线` 三行之间上下切换导航。

## 星途程序化视觉系统（0 外部贴图资产）

- **多层程序化卡图**：基于卡牌 ID 的确定性 FNV-1a 哈希种子派生，包含双焦点深空星云渐变、三大阵营精密底纹（绮梦/红裤衩系极坐标魔法星盘、理惠/溯光系机甲装甲切面与光学 HUD 准星、通用等高晶格）、双层复合主徽记、景深星尘星座连线与四角稀有度切角辉光（真图通道仍保留，有真图时优先）。
- **全局视觉与微交互**：FastNoiseLite 多层视差星空背景、路线地图贝塞尔曲线爬升节点（`MapPathView`）、按钮悬停缩放提亮（`MicroFX`）、敌我底座光环（`HeroAuraRing`）、护甲获得 `🛡+N` 跳字与老电视风双向表情飘字系统。

## 配套可视化工具：星图档案（`Tools/CardCollectionWeb`）

仓库内置对标 KARDS 官网体验的独立 TypeScript + React 全栈应用：

- 实时读取 `Resources/Cards/*.tres` 与中英 YAML，零静态副本延迟；
- 提供高精度 DPR HTML5 Canvas 程序化卡图陈列、多维兵种/油费/词条筛选、大图检视台与衍生卡跳转；
- 内置卡组构筑器（10~20 张校验、费用曲线、兵种统计、一键按种子模拟生成 20 张主题卡组、导入导出）；
- 内置**可交互 `4 / 5 / 4` 防线规则沙盘**，可自由摆放四兵种与嘲讽/守护/护航/烟幕单位，实时高亮合法目标并输出拦截破锁分析。
