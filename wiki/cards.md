# 卡牌

本页记录出现过的玩家卡牌/状态牌概念。资源是否存在不等于 UX 已完整可用。

## 卡牌类型

- 随从：部署到棋盘，拥有攻击、生命、防御、行动花费、关键词和标签。
- 法术：从手牌打出后立即生效，可以有目标或无目标。
- 领域：展开后挂在英雄/战斗侧，持续生效；同名领域可叠层。
- 状态牌：战斗内临时负面或干扰卡，不应进入永久卡组。

## 稀有度

- 0：衍生卡，无法自然获得。
- 1：大师级/金卡。
- 2：极佳/银卡。
- 3：良好/铜卡。
- 4：普通/铁卡。
- 5：角色专属特殊卡。
- 6：状态牌。

历史设计中，1~4 也表示单次奖励中同名最大张数。

## 机制标签（CardMechanicTag）

概念已实现（代码中有 `CardMechanicTag` enum + `CardData.MechanicTags` 字段）。描述「这张卡做什么」的高层语义，与种族标签（`CardTag`，如机械族）正交。一张卡可同时拥有多个机制标签（`[Flags]` 位掩码）。

当前已定义的标签（按位掩码递增，预留扩展空间）：

| 位掩码 | 标签 | 语义 |
|--------|------|------|
| 0 | `None` | 无机制标签（通用卡） |
| 1 | `DirectDamage` | 直伤：直接造成伤害的卡（含单体/AOE/英雄直击） |
| 2 | `DamageOverTime` | 持续伤害：以状态形式延迟结算的伤害 |
| 4 | `Heal` | 治疗：恢复生命或最大生命值 |
| 8 | `Armor` | 护甲：获得护甲值 |
| 16 | `Draw` | 抽牌：从抽牌堆获取卡牌 |
| 32 | `Discover` | 发现/检索：选择性获取卡牌（Discover/ChooseFromDiscard） |
| 64 | `Summon` | 召唤：直接召唤随从或将卡牌洗入抽牌堆 |
| 128 | `Buff` | 增益：强化随从（+攻/+血/关键词授予） |
| 256 | `Silence` | 沉默/解场：移除关键词或处理敌方威胁 |
| 512 | `Discard` | 弃牌：主动弃牌或弃牌联动 |
| 1024 | `Domain` | 领域：持续性场地效果（CardType.Domain 或领域联动卡） |
| 2048 | `WeaponSynergy` | 武器协同：与武器攻击/武器技能联动 |
| 4096 | `ManaRamp` | 法力增益：增加法力槽/突破上限/临时增益 |
| 8192 | `StatusApply` | 状态施加：给目标挂 StatusEffect（含增益/减益） |
| 16384 | `Shuffle` | 洗牌：将某牌洗入抽牌堆（干洗/衍生洗入） |
| 32768 | `Token` | 衍生牌：将某指定牌加入手牌（Token 生成） |

语义规则：
- `发现`（Discover）是 `衍生牌`（Token）的真子集——所有发现都是衍生牌的特例，打发现标签的卡同时打衍生牌。
- `洗牌`（Shuffle）强调「洗入某牌到抽牌堆」，`召唤`（Summon）强调「召唤随从到棋盘」。
- 战斗关键词（闪击/嘲讽/亡语等）不属于机制标签，见 `Keyword` enum，避免重复维度。

标签由人工填写为权威数据，不从 `CardEffectType` 自动推导——同一 EffectType 在不同 Value/Target 下语义可能不同。标签扩展是纯加法（新增 2^幂位），零回归。

## 主题卡组生成（Roguelite 主题选牌）

概念已实现（代码中有 `ThemeProfile` 资源 + `ThemedDeckGenerator` 生成器 + `ThemedDeckSelectUI` 选择界面）。

玩家可以 0 牌开局进入 roguelite 模式：从 3 套随机主题卡组（绮梦/理惠/溯光）中选一套 20 张卡组开始。英雄与卡组角色可以不同（如选绮梦英雄但用理惠的直伤卡组）。

### ThemeProfile

每个角色定义主题画像：
- **标签偏好权重表**（TagWeights）：正=偏好，负=不擅长，0=中性。权重值随时可改，是数值平衡切入口。
- **核心池**（CoreCardIds）：5-8 张招牌卡，生成时几乎必带，保证角色识别度。核心池卡牌随时可改。
- **人工 override**（CardWeightOverrides）：特殊关联（剧情/设定/combo）的额外权重。

### 生成算法

```
20 张 = 核心池招牌卡（几乎必带）+ 加权随机填充 + 软约束（法力曲线/随从比例）
```

权重计算：`Σ(标签权重 × 卡的标签命中) + 人工 override`，最小 clamp 到 1。

| 角色 | 主题名 | 偏好 | 不擅长 |
|------|--------|------|--------|
| 绮梦 | 守护续航 | 治疗/护甲/抽牌/领域/增益 | 直伤/弃牌 |
| 理惠 | 直伤爆发 | 直伤/持续伤害/武器协同/抽牌 | 治疗/护甲/领域 |
| 溯光 | 牌堆操控 | 弃牌/洗牌/抽牌/发现/衍生牌/武器协同 | 治疗/护甲/领域 |
