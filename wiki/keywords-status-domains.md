# 关键词、状态与领域

## 关键词

| 关键词 | 英文/代码 | 概念 |
|---|---|---|
| 闪击 | Charge | 召唤的回合即可攻击。旧 GDD 写作“冲锋”，当前 README/代码注释偏向“闪击”。 |
| 嘲讽 | Taunt | 敌方攻击必须优先选择嘲讽随从。 |
| 战吼 | Battlecry | 从手牌打出随从时触发。 |
| 亡语 | Deathrattle | 随从死亡时触发。 |
| 风怒 | Windfury | 每回合可以攻击两次。 |
| 伏击 | Ambush | 每回合首次被攻击时，先于攻击者造成反击伤害；若击杀攻击者，则取消原攻击。 |
| 冲击 | Impact | 攻击时抵消所有反击伤害，一次性消耗。 |
| 轮战 | Recycle | 法术打出后回到抽牌堆底部；随从被击败后回到抽牌堆底部。旧设计曾是随机位置，已标记为旧表述。 |
| 不可打出 | Unplayable | 无法从手牌主动打出，只能通过弃牌、消耗或其他机制移除。 |
| 虚无 | Ethereal | 回合结束时自动消耗，不进入弃牌堆。 |
| 奇巧 | Qiqiao | 被弃掉时将这张牌打出；法术/领域直接打出，随从召唤到最左侧空槽，无槽则消失。 |

## 状态效果

| 状态 | 概念 |
|---|---|
| 易伤 | 受到伤害提高；当前实现语义为受到伤害 ×1.5。 |
| 虚弱 | 造成伤害降低；当前实现语义为造成伤害 ×0.75。 |
| 脆弱 | 护甲获得量降低；当前实现语义为护甲获得 ×0.75。 |
| 总观效应 | 翻倍易伤/虚弱/脆弱效果：易伤 1.5→2.0，虚弱/脆弱 0.75→0.5。 |
| 熔毁 | 离子手枪命中后施加；目标防御力 -1，最多 2 层。 |
| 武器禁用 | 使英雄武器无法攻击/反击。 |
| 攻击归零 | 离子脉冲对随从使用时出现，攻击力变为 0 一段时间。 |
| 磁轨锁定 | 磁轨手枪命中后出现，使目标 1 回合内无法攻击。 |
| 难逃之瑕 | 负面领域效果；持有者失去一种负面效果时，立刻随机获得 1 层一种负面效果。若失去的是本效果，也可能重新获得本效果。当前实现挂在领域层而不是临时状态层。 |
| 固璋 | 张郎被动，单次生命伤害上限 3。 |
| 不破 | 珊胡被动，每回合只能受到一次生命伤害。 |

## 领域

领域是不随时间自然减少的持续效果。与易伤、虚弱、脆弱这类会随回合减少的状态不同。

| 领域 | 来源 | 概念 |
|---|---|---|
| 执锐 | 卡牌「执锐」 | 友方随从部署时攻击力 +1。 |
| 无限火力 | 卡牌「无限火力」 | 友方回合结束时洗入「打击」。 |
| 无限潜能 | 卡牌「无限潜能」 | 解除自然增长水晶槽上限。 |
| 偶像的黄昏 | 卡牌「偶像的黄昏」 | 持续领域：挂在玩家英雄上，友方随从被攻击后获得 +1/+1。领域展开后召唤/抽到的新随从也生效。 |
| 飞远 | 卡牌「飞远」 | 被攻击后抽2张牌并获「受身」。 |
| 接化发 | 卡牌「接化发」 | 敌方回合结束时，若英雄攻击全被格挡，获「受身」。 |
| 宇宙冷漠 | 宇宙员 | 每层使所有「解释」费用 +1。 |
| 聚焦 | 劫蛋者 / 智能臭鸡蛋 | 每层使造成的法术伤害 +1。当前实现为永久领域，作用于 `DamageKind.Effect`。 |
| 蓄谋 | 劫蛋者 | 每层使该英雄召唤的智能臭鸡蛋入场时额外获得 1 层聚焦。 |

## 待确认

- 中文名“闪击”与旧 GDD 的“冲锋”是否统一为“闪击”。
- 「解释」的“打出后回到手牌并进入不可打出状态”是否已经是最终设计。
- 「难逃之瑕」是否最终坚持作为“负面领域”而非“特殊状态”；当前实现以代码与实际 UX 为准。
