# 关键词、状态、情报与领域

## 关键词

| 关键词   | 英文/代码   | 概念                                                                                                                               |
| -------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 闪击     | Charge      | 解除随从部署当回合的整备冷却，按所属兵种解锁当回合移动/攻击配额（先锋移或攻，突击可移+攻，支援/游击可原地跨线攻）。                |
| 嘲讽     | Taunt       | 重装全局防线：保护同阵线所有友方随从并保护己方英雄 HQ；与烟幕互斥。                                                                |
| 守护     | Guard       | 轻步邻格掩护：仅保护同阵线左右紧邻槽位（`slot ± 1`）的非嘲讽、非守护随从，不保护 HQ；与烟幕互斥。                                  |
| 战吼     | Battlecry   | 从手牌打出随从时触发。                                                                                                             |
| 亡语     | Deathrattle | 随从死亡时触发（移动或召回离场不触发）。                                                                                           |
| 风怒     | Windfury    | 单回合攻击配额上限提升为 2 次。                                                                                                    |
| 伏击     | Ambush      | 每回合首次被普通攻击时先于攻击者造成反击伤害并替代当次普通反击；若击杀攻击者则取消原攻击。支援兵种与免反击武器主动攻击不触发伏击。 |
| 冲击     | Impact      | 主动普通攻击时抵消所有反击伤害（含伏击先手伤害），结算后一次性消耗。                                                               |
| 轮战     | Recycle     | 法术打出后回到所属指挥官抽牌堆底部；随从被击败后回到所属指挥官抽牌堆底部。                                                         |
| 不可打出 | Unplayable  | 无法从手牌主动打出，只能通过弃牌、消耗或其他机制移除。                                                                             |
| 虚无     | Ethereal    | 回合结束时若仍在手牌则自动消耗，不进入弃牌堆。                                                                                     |
| 奇巧     | Qiqiao      | 被弃掉时自动打出；随从召唤至所属方支援线空槽，支援线满 4 格则溢出消失。                                                            |

## 情报与溢出情报

配合「道中意图小怪 + 精英/Boss 主题卡组指挥官」双轨架构引入的核心侦察机制：

- **情报 N（Intel N）**：
  - 面对拥有手牌体系的敌方指挥官时，按敌方手牌**从左往右**的顺序依次翻开最多 `N` 张尚未公开的暗牌，使其永久变为明牌（显示在战斗界面顶部敌方手牌栏，可悬停放大查看完整牌面）。
  - 同名不同卡牌实例独立记录公开状态，洗回牌堆或回手时保留已公开标记。
- **溢出情报（Excess Intel）**：
  - 当敌方为无手牌架构的道中意图小怪，或敌方指挥官当前未公开暗牌不足 `N` 张时，未消耗的情报点数自动转化为等量**溢出情报**。
  - **默认基础收益**：每 **1 点溢出情报**立即为己方英雄**回复 1 点生命值**；若该点结算时英雄已满血，则自动转为**获得 1 点格挡（护甲）**。
  - 基础收益结算后广播 `OnIntelOverflow` 事件，供后续专属卡牌与藏品扩展进阶联动。

## 状态效果

| 状态     | 概念                                                                                                                                          |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 易伤     | 受到伤害提高；当前语义为受到伤害 ×1.5。                                                                                                       |
| 虚弱     | 造成伤害降低；当前语义为造成伤害 ×0.75。                                                                                                      |
| 脆弱     | 护甲获得量降低；当前语义为护甲获得 ×0.75。                                                                                                    |
| 持续伤害 | 单位所属方回合开始时受到固定直伤（不走伤害管线），随后层数减 1。理惠 SVDS-M338 被动施加。                                                     |
| 失能     | 负面状态，按目标所属方回合结束衰减；失能单位不能移动、主动攻击、触发伏击或反击，失能英雄不能用武器攻击但仍可施放法术。                        |
| 烟幕     | 正面掩蔽状态；拥有烟幕的随从或英雄无法成为任何敌方随从或武器普通攻击的目标（含远程与游击），仍可被法术、AOE 与强制互殴命中。与嘲讽/守护互斥。 |
| 总观效应 | 翻倍易伤/虚弱/脆弱幅度：易伤 1.5→2.0，虚弱/脆弱 0.75→0.5。                                                                                    |
| 熔毁     | 离子手枪命中后施加；目标防御力 -1，最多 2 层。                                                                                                |
| 武器禁用 | 使英雄武器无法攻击或反击。                                                                                                                    |
| 攻击归零 | 离子脉冲对随从使用时施加，攻击力变为 0 持续一段时间。                                                                                         |
| 磁轨锁定 | 宇宙员磁轨手枪命中后施加，使目标 1 回合内无法行动攻击。                                                                                       |
| 难逃之瑕 | 负面领域效果；持有者失去一种负面效果时，立刻随机获得 1 层另一种负面效果。                                                                     |
| 固璋     | 张郎被动，单次受到的生命伤害上限为 3。                                                                                                        |
| 不破     | 珊胡被动，每回合只能受到 1 次生命伤害（0 点生命伤害不计次数）。                                                                               |

## 领域与限时挂载效果

领域是不随时间自然衰减的永久型持续效果（`ActiveDomain`，Counter 仅由战斗事件消耗）；四夜雷电光「4 回合伤害」与星途精神「下回合额外抽牌/法力」属于限时挂载效果（走 `StatusEffect + OnTick` 通道，归零自动移除）。目前领域系统已支持敌我双方指挥官对称挂载与触发。

| 领域       | 来源                | 概念                                                                                                            |
| ---------- | ------------------- | --------------------------------------------------------------------------------------------------------------- |
| 执锐       | 卡牌「执锐」        | 所属方随从部署到支援线时攻击力 +1。                                                                             |
| 无限火力   | 卡牌「无限火力」    | 所属方回合结束时洗入 1 张「打击」至抽牌堆。理惠宿敌指挥官开场自带。                                             |
| 无限潜能   | 卡牌「无限潜能」    | 解除自然增长法力水晶槽上限（12 → 30）。                                                                         |
| 偶像的黄昏 | 卡牌「偶像的黄昏」  | 所属方随从在任意阵线被攻击后获得 +1/+1。                                                                        |
| 先发制人   | 卡牌「先发制人」    | 每回合打出的首张直伤牌，手牌中每有 1 张牌便使其基础伤害提高 10%。                                               |
| 飞远       | 卡牌「飞远」        | 展开获 5 格挡；下一次所属英雄本体被敌方攻击时，抽 2 张牌并获得「受身」，随后消耗领域。                          |

| 宇宙冷漠   | 宇宙员              | 每层使所有「解释」费用 +1。                                                                                     |
| 聚焦       | 劫蛋者 / 智能臭鸡蛋 | 每层使造成的法术伤害 +1（作用于 `DamageKind.Effect`）。                                                         |
