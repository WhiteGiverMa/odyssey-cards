# 路线、房间与奖励

## Roguelike 路线

游戏循环概念：

```text
主菜单 → 地图 → 战斗 → 胜负判定 → 奖励 → 地图 → ... → Boss → 通关/失败
```

第一位面设计：

```text
战斗（入口）→ [事件/商店/奖励/战斗] ×4 → Boss
```

## 房间类型

| 房间   | 概念                                                                                                             |
| ------ | ---------------------------------------------------------------------------------------------------------------- |
| 战斗   | 标准战斗房间。                                                                                                   |
| 事件   | 事件房间；存在 UI/数据概念。支持英雄专属事件——可根据当前英雄 ID 动态追加专属事件到池中（如绮梦的「镜中自我」）。 |
| 商店   | 商店房间；存在 UI 概念，流程接入以实际 UX 为准。                                                                 |
| 奖励   | 奖励房间；用于获得卡牌、藏品等。                                                                                 |
| Boss   | 位面终点战斗。                                                                                                   |
| 休息处 | UI 概念存在，流程接入以实际 UX 为准。                                                                            |

## 战后奖励

- 战斗胜利后出现 3 选 1 战利品的概念。
- EventSelector 使用 Fisher-Yates 洗牌算法这一实现备注曾出现。
- 卡牌奖励与发现 UI 都采用“N 选 1/多选卡牌界面”的概念。

## 卡组与收藏

- 构筑卡组最小 10、最大 20；敌方同构牌手则按位格区分卡组厚度（普通 10~20 / 精英 21~39 / Boss 40）。
- 战斗奖励加入运行中牌堆可以突破构筑上限，但不应写回构筑卡组。
- 收藏界面支持浏览、编辑、分页、按类型（随从/法术/领域/反制）与按**卡包系列**（核心/无人智胜/未来追杀/超体计划/断流/预备/先锋/DIY）过滤、保存/不保存。
- **战斗启用卡包管理（0.2.1）**：玩家可在收藏界面打开「卡包管理」弹窗，自由勾选在战斗（主题卡组生成、敌方卡组、发现池、战后奖励池）中启用或禁用哪些扩展包（「核心」包恒定启用，「预备」包默认禁用）。
- 后续概念：
  - Start 前弹出牌组确认界面。
  - 卡牌解锁机制：在奖励中见过 → 解锁。
  - 稀有度影响奖励出现率。
  - 牌组命名。
  - 费用曲线可视化。
  - 存档云同步。

## 暂停菜单

战斗中按 ESC 或点击暂停进入。

概念功能：

- 继续游戏。
- 设置。
- 保存并退出：保存房间进度，不保存战斗状态。
- 快速 SL：重打当前战斗。

## 综合信息界面

- 默认 CapsLock 呼出。
- 查看当前关卡层数/房间。
- 查看当前卡组。
- 查看已获得藏品。
- 类似模拟宇宙/差分宇宙的祝福与奇物浏览界面。
