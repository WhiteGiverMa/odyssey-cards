## 棋盘

- 2×5 棋盘：玩家 5 个槽位（下方），敌方 5 个槽位（上方）
- 槽位从 0 到 4 编号
- 嘲讽检测：敌方随从必须优先攻击具有嘲讽的友方随从

## 法力水晶

| 参数 | 值 | 状态 |
|------|-----|------|
| 游戏开始时 | 3 费 | 🚧 |
| 每回合开始 | +1 费（并回满） | ✅ |
| 第一回合开始总计 | 4 费 | 🚧 |
| 自然增长上限 | 12 | 🚧 |
| 硬上限 | 30 | 🚧 |
| "获得额外水晶槽" | 可突破自然上限 | 🚧 |

> 设计：「游戏/战斗开始」和「玩家回合开始」是两个独立阶段。
> - 战斗开始：场景初始化、生命值/费用初始化、发 5 张初始手牌
> - 回合开始：回满费、+1 水晶槽、抽 1 张牌
> - 玩家总是先手。敌人没有费用概念（采用尖塔式意图系统）。

## 行动花费

随从攻击时需消耗法力水晶（类似 KARDS）。

- 显示位置：卡牌左上角费用（部署费，蓝色）右下方，红色小矩形
- 默认所有随从行动花费 = 0，当前第 18 团行动花费 = 1
- 状态：🚧 部分

## 武器系统

英雄出场自带武器（非炉石式装备）。武器有攻击力、攻击花费、主动/被动技能。

### ✅ 玩家默认武器：离子手枪

| 属性 | 值 |
|------|-----|
| 攻击力 | 2 |
| 攻击花费 | 3 费 |
| 被动技能 | **熔毁** — 敌方目标（英雄和随从）被武器攻击或武器主动技命中时，防御力 -1，最多叠加 2 层 |
| 主动技能 | **离子脉冲** — 4 费，每 3 个友方回合可释放一次。可使敌方英雄武器禁用 2 回合**或**使一个敌方随从攻击力为 0 两回合 |

- 武器攻击目标：敌方英雄或敌方随从
- 攻击造成等同于攻击力的基础伤害
- 受到目标武器攻击力的反击伤害（无武器则攻击力=0）
- 每回合武器可攻击次数：默认 1 次
- 无限使用，无耐久
- 武器主动技能为独立按钮

### ✅ 敌方默认武器：棍木

| 属性 | 值 |
|------|-----|
| 攻击力 | 1 |
| 攻击花费 | 无（敌人无费用概念） |

- 纯被动，敌人不主动使用武器
- 只影响玩家攻击敌人时的反击伤害
- 攻击力**会**影响意图造成的伤害（附加到意图伤害上）

## 防御力

影响受到伤害的参数。

| 防御力值 | 效果 |
|----------|------|
| +N | 受到的伤害 -N |
| -N | 受到的伤害 +N |
| 0 | 无影响 |

规则：
- 防御力影响意图显示——意图以最终造成的伤害为准
- 敌方武器攻击力附加到意图伤害上
- Clamp：防御力不能使伤害变为负（不能回血），最小伤害为 0
- 防御力对玩家和敌方双方的英雄和随从都适用
- 减少敌方攻击力 → 减少敌方意图伤害；减少玩家攻击力 → 不影响玩家法术伤害
- 状态：🚧 部分

- 下次战斗继承上一场结束时的生命值
