## 卡牌类型

| 类型 | 说明 | 状态 |
|------|------|------|
| 随从 (Minion) | 部署到 2×5 棋盘上，有攻击力/生命值/关键词 | ✅ |
| 法术 (Spell) | 从手牌打出立即生效 | ✅ |
| 领域 (Domain) | 给玩家英雄上持久 buff，类似杀戮尖塔中的能力牌。同类型效果可堆叠。领域 buff 挂载在玩家英雄身上，只要 buff 在就持续生效。 | 🚧 |

## 稀有度系统

| 稀有度 | 名称 | 说明 |
|--------|------|------|
| 0 | 衍生卡 | 无法自然获得（如「计划」） |
| 1 | 大师级 / 金卡 | 最高稀有度 |
| 2 | 极佳 / 银卡 | |
| 3 | 良好 / 铜卡 | |
| 4 | 普通 / 铁卡 | 最低常规稀有度 |
| 5 | 角色专属的特殊卡 | 0~4以外的稀有度卡，不在常规的稀有度以内 |

> 稀有度目前对游戏性无影响（卡牌奖励系统未完成），但需要在卡牌数据中标注。
> 0~4的稀有度值，实际意义上是「单次卡牌奖励中这张卡作为选项出现时的同名最大张数」，比如某次奖励中可以出现「金卡x1，铜卡x2，铁卡x4」，也可以「金卡x1，另一张金卡x1，银卡x2」，但没法出现「金卡x2，铜卡x4」等选项。
> 金卡可以在卡组中同时存在两张一样的，比如我在两次选卡奖励中分别选到1张同名金卡。

## 手牌交互设计

### 两种等效的打出方式

**点击模式**：左键点击卡牌 → 选中（卡牌跟随鼠标）→ 左键点击有效目标 → 打出卡牌；右键 → 取消归位

**拖拽模式**：左键按住卡牌 → 拖动（卡牌跟随鼠标）→ 松开在有效目标上 → 打出；松开在无效区域 → 取消（等效右键）

### 交互规则

- 右键取消：无论当前状态和位置如何，只要右键，就取消当前卡牌选择
- 卡牌锚点：基于手牌数量和卡牌索引动态计算位置
- 点击选中一张卡牌时，若之前有卡牌被选中，先取消前一张
- 随从的打出目标 = 友方棋盘槽位
- 有目标法术的打出目标 = 法术指定的有效目标
- 无目标卡牌（如「警戒」「无限火力」）= 拖动到屏幕中间的 PlayZone 判定区域或点击打出

### 打出目标范围

| 卡牌类型 | 有效目标 |
|----------|----------|
| 随从 | 友方棋盘空槽位 |
| 有目标法术 | 法术指定的敌方/友方目标（随从、英雄） |
| 无目标法术/领域 | PlayZone 判定区域（屏幕中间大片区域） |
