## 路线选择（Roguelike Route）

类似崩坏星穹铁道模拟宇宙/差分宇宙的路线选择系统。

### 第一位面

6 个房间，线性推进：

```
战斗（入口）→ [事件/商店/奖励/战斗] ×4 → Boss
```

| 房间类型 | 说明 | 状态 |
|----------|------|------|
| 战斗 | 标准战斗房间 | ✅ |
| 事件 | 事件房间 | ⬜ 占位符 |
| 商店 | 商店房间 | ⬜ 占位符 |
| 奖励 | 奖励房间 | ⬜ 占位符 |
| Boss | 面底 Boss 战 | 🚧 有占位符 Boss |

- 中间 4 个非战斗房间目前只做占位符
- Boss 非纯占位符，需能和玩家正常对战
- 需要一个「路线/房间管理器」来管理全局路线状态

状态：🚧 基础框架已实现（MapUI、GameRunState），房间选择流程跑通。

## 暂停菜单

战斗中按 ESC 或右上角暂停按钮触发。

功能：
- 继续游戏
- 设置（含语言切换，复用主菜单设置界面）
- 保存并退出（保存房间进度，不保存战斗状态）
- 快速 SL（重打当前战斗）

UI 要求：
- 全屏半透明暗色背景
- 菜单居中

状态：✅ 已实现。
