# 杂谈：飞远与受身——战斗漫的公式画面

## 灵感

「飞远」这个设计的原点，是战斗动漫里被轮播了无数次的一个画面：

> 角色正面接下了强敌的一击——挡是挡住了，但整个人还是被打飞出去，在地上弹了两下，然后趁势用手撑地增加摩擦力，拉出一道长长的痕迹，最终稳住身体。站起来的时候已经调整好了呼吸，甚至嘴角微微上扬。

这个画面如此常见，以至于看到它的时候你不会觉得"这很帅"，而是"哦，又来了"。但正是这种"又来了一遍"的感觉，说明它已经沉淀成了类型语法的一部分——不是某个角色的绝招，是整个战斗叙事里共享的节奏点。我方角色被打飞 → 在空中/落地后调整 → 回到战斗。三段式的小循环，插入在更长的回合制对峙之间。

所以做成了**领域卡**。领域卡在 Odyssey Cards 里对应的是半永久效果——它不只是打出一次的法术，而是"从这回合开始，你获得了这个能力"。和战斗漫里那个画面一样：不是某个技能有击飞效果，而是每个角色在面对强大攻击时都可能被击飞，而每次被击飞时都可能做出调整。

## 机制翻译

「飞远」的卡面效果：

> 获得 5 点格挡。下一次被敌方随从或英雄攻击时，抽 2 张牌，将一张「受身」加入手牌。

拆开看机制翻译：

| 叙事 | 机制 |
|------|------|
| 架起防御准备迎接冲击 | 获得 5 点格挡 |
| 被击中，整个人被打飞 | 被攻击触发 |
| 在空中/落地时趁乱调整姿态、观察对手破绽 | 抽 2 张牌 |
| 调整完毕，重新站稳，回到战斗 | 将一张「受身」加入手牌 |

「受身」是一张 0 费衍生法术：获得 3 点格挡，抽 1 张牌。格挡代表站稳脚根，抽牌代表从刚才那一击里学到了东西。0 费意味着调整不需要额外花费行动资源——本来就是趁乱完成的。

## 「受身」这个词

受身（うけみ / ukemi）是格斗游戏术语：角色被击飞后，在空中可以重新获得控制权——调整落点、恢复姿态、甚至直接发动反击。

但这里要诚实地说：格斗游戏里的"受身"和那张战斗漫画面其实不太一样。真正的受身更像是——

> 你被一记升龙拳打飞到半空，按照牛顿第三定律你应该继续飞，但你的角色在空中**毫无征兆地直接"站起来了"**，双脚踩在空气上，稳稳落地。

这纯粹是游戏性的产物——给被连招的玩家一个逃脱窗口。没有减速过程，没有撑地摩擦，就是"啪"一下在空中恢复站立姿势。很实用，但一点也不帅。

而战斗漫里的飞远画面，恰好在"帅"和"不科学"之间取了一个折中：角色确实被击飞了，调整是在飞的过程中（或落地后）完成的，没有违反物理——只是把物理用到了极致。手撑地、划痕减速、利用飞出去的这段距离来拉开对手的追击范围——这些都是真实的格斗技术（柔道里的受身本来就是这个意思——被摔出去时如何卸力）。

所以「受身」在这套设计里，其实更接近柔道的受身，而不是格斗游戏的受身。但名字还是用了格斗游戏的叫法——因为"受身"这两个字本身就很准确："承受"之后的"恢复"。不管是空中凭空站起来的游戏魔法，还是手撑地减速的硬核技术，本质都一样——

> 趁飞远的时候调整。

## 4 费史诗

4 费的定位意味着它不是前期就能随便拍出来的东西。你需要在被打飞之前就预判到——在战斗节奏中留出 4 费的余裕，提前铺好领域。这要求玩家具备一种"知道自己可能会被击飞"的战术意识。

而一旦拍出来，它就是整场战斗都在的半永久能力——不是一次性保命，是"从此以后，每次被击飞都是机会"。

和战斗漫里的画面对应的，正是这种感觉：不是某一次被打飞之后的表现有多帅，而是这个角色**每次被打飞之后都这样**。它成了他的战法风格。

这就是领域卡的意义——它不是一个法术，而是一个叙事声明。
