# 杂谈：飞远与受身——战斗漫的公式画面

## 灵感

「飞远」这个设计的原点，是战斗动漫里被轮播了无数次的一个画面——

> 角色正面接下了强敌的一击——挡是挡住了，但整个人还是被打飞出去，在地上弹了两下，然后趁势用手撑地增加摩擦力，拉出一道长长的痕迹，最终稳住身体。站起来的时候已经调整好了呼吸，甚至嘴角微微上扬。

这个画面如此常见，以至于看到它的时候你不会觉得"这很帅"，而是"哦，又来了"。但正是这种"又来了一遍"的感觉，说明它已经沉淀成了类型语法的一部分——不是某个角色的绝招，是整个战斗叙事里共享的节奏点。

所以做成了**领域卡**。在 Odyssey Cards 里领域卡属于能力牌——给玩家一个持续生效的效果。但和尖塔那种"整场战斗都在"的能力牌不同，「飞远」更像尖塔的**「缓冲」**——只要敌人不打你，它就挂在身上；一旦被攻击，触发效果之后就没啦。

一开始想说"半永久效果"，但其实这个词不太准确。4 费不是买了一个整场战斗的被动，而是买了一次**"被击飞时我有个调整机会"**的保险。如果敌人一直不碰你——OK，那就一直在那儿挂着。但只要挨了一下，飞远就被消耗掉了。所以 4 费到底值不值，取决于对面有没有打你——以及打你的时候你准备好了没有。www

## 机制翻译

「飞远」的卡面效果：

> 获得 5 点格挡。下一次被敌方随从或英雄攻击时，抽 2 张牌，将一张「受身」加入手牌。

拆开看机制翻译：

| 叙事 | 机制 |
|------|------|
| 架起防御准备迎接冲击 | 获得 5 点格挡 |
| 被击中，整个人被打飞 | 被攻击触发（之后领域移除） |
| 在空中/落地时趁乱调整姿态、观察对手破绽 | 抽 2 张牌 |
| 调整完毕，重新站稳，回到战斗 | 将一张「受身」加入手牌 |

触发后领域就消失了——因为你已经"飞远"过了。再飞一次？再打一张飞远呀（如果有第二张的话）。这不是永续光环，是一个**待发的应急方案**。你提前 4 费把它铺好，然后在被攻击的时候它自动帮你转成格挡 + 抽牌 + 受身——不需要你再花行动资源去反应。这才是领域卡的意义：把一件事提前做好了预算，事到临头不需要临时掏钱。

「受身」是一张 0 费衍生法术：获得 3 点格挡，抽 1 张牌。格挡代表站稳脚根，抽牌代表从刚才那一击里学到了东西。0 费意味着调整不需要额外花费行动资源——本来就是趁乱完成的。你甚至可以说「受身」的存在让被击飞这件事**变成了正收益**：你挨了一下，但受了 5（飞远）+3（受身）共 8 点格挡，还抽了 3 张牌。如果对面那一击的伤害小于 8，你实际上是赚的。

这大概就是战斗漫主角嘴角上扬的原因吧——不是被打不痛，是被打了之后还能比对面多拿几张牌。w

## 「受身」这个词

受身（うけみ / ukemi）是格斗游戏术语：角色被击飞后，在空中可以重新获得控制权——调整落点、恢复姿态、甚至直接发动反击。但一般格斗游戏里的受身比较魔法——你被打飞到半空，然后**毫无征兆地在空气里直接"站起来了"**。没有减速过程，没有撑地摩擦，就是凭空恢复站立姿势。很实用，但确实不太科学。www

而战斗漫里的那种飞远画面，恰好是另一种风格——角色确实飞了，调整是在落地过程中完成的，或者落地后缓冲减速。它是"可以解释的帅"：手撑地、划痕减速、利用飞出去的这段距离不让自己被追击。柔道里的受身本来就是这个意思——被摔出去时如何卸力、如何不受伤地落地。

所以这卡虽然叫「受身」，但演出的其实是战斗漫那种"手撑地划痕"的落地受身，而不是格斗游戏里空中凭空站起来的那种。不过叫"受身"确实比叫"战斗漫里那个飞出去然后撑地的动作"简洁多了嘛。w

## 碎碎念

4 费对于一张"可能整场都不触发"的卡来说……其实还挺贵的？如果对面是那种高频率多段攻击的卡组，你飞远刚铺下去就被小怪蹭掉了，基本等于 4 费买 5 格挡 + 2 抽牌 + 一张 0 费受身——还行吧，但也不是特别赚。

但如果对面是个一拳超人型的大哥卡组——每回合只打一下但伤害爆炸——那你提前铺好飞远，被大哥捶飞之后格挡抵消大半伤害，抽 3 张牌，然后笑嘻嘻地把受身拍出来继续循环。那个体验就很有"你是高手，你能预判"的感觉了。

这也是 Odyssey Cards 想做的方向：让玩家的决策更像读对手、读节奏，而不是单纯数值博弈。你知道对面会打你，你提前 4 费铺好了退路——这不是保守，是战术。w

最后说一个特别中二但我很喜欢的设计细节：飞远的效果触发之后，领域就移除了——因为"你已经飞过了"。下一次再被击飞？抱歉，那是一张新的飞远卡。人生没有两次相同的被击飞。www

## 作者注
- 飞远这张卡其实就是我对「跨回合收益卡的一种典型」的理解。
- 实际上一切跨回合收益问题都是数值问题：值得等吗？风险大吗？收益和风险必须是「对等、可接受或者可预见」的。
- 对于一张不合格的跨回合收益卡，「有命出这张卡，没命拿它的收益」是常有的事。目前星途卡牌处于急速膨胀期，以后这张卡的数值可能过高或者过低，但我先阐明我的设计意图：我希望「飞远」能在打出的当回合获得一个可观但性价比不高的格挡值，并在后续回合获得可观的收益和灵活性，前后加起来的价值需要大于4费，牌效在即时的6费左右。
